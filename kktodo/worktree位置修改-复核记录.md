要求：验证将要创建的真实子群路径；必要时以目录形式检查，避免否定目录规则在尚不存在时产生不同结果。可预分配子群 ID 后检查，或创建元数据后检查失败完整回滚；失败不得启动 worktree 或 agent，不得残留子群。补测只忽略 probe、实际路径被否定忽略规则，以及正常整体忽略的情况。

证据：`/private/tmp/kkagent-worktree-review-8_f4swav/result.json`，使用真实 git 的临时仓库；没有创建正式 worktree 或启动 agent。
