# 在群里直接新建会话（KK 提，2026-11-13）

## 要解决什么

现在「添加成员」只能填一个已有会话的 ID：要先在终端里自己开好会话、问它会话 ID，再回 kkAgent 粘贴。
KK 要的是在群里直接点「新建会话」，由 kkAgent 起一个新会话，自动加进这个群。

## KK 已经定的

1. Claude 只建在虚拟机里，和集群 coder 的规则一致，禁止在物理机上建。Codex 只支持物理机，固定建在物理机。
2. 工作目录：**第一步就选工作代码路径**。路径输入框加「选择文件夹」按钮；群里已经有成员时，默认填第一个成员的工作目录。
3. 流程照老规矩：先出方案给 pm 评审，再在测试核心上写代码、真机验证，pm 通过后等 KK 说再换正式环境。

## 做法：复用集群子群那套 tmux 托管

新建出来的成员和集群的 coder / tester 一样，由核心托管在 tmux 里：
能在 kkAgent 里打开终端交互、退出后能重新打开、有状态 hook（Claude）、忙闲判断准确、能被紧急消息打断。
所以几乎不用新写投递逻辑，只是加成员的入口不同。

### 界面（AddMemberSheet）

- 顶部加一个分段选择「新建会话 / 拉入已有会话」，默认「新建会话」。
- 新建会话的表单，从上到下：
  1. **工作目录**（第一项）：路径输入框 +「选择文件夹…」按钮（NSOpenPanel，只能选目录）；默认填群里第一个成员的工作目录，群是空的就留空。
  2. 类型：Claude / Codex。选 Claude 时显示一行说明「建在虚拟机里」。
  3. 成员名、负责什么：和现在一样。
- 按钮「新建并加入」。目录、成员名没填时置灰。可点的地方都加 `.clickable()`。

### 接口

- `AddMemberRequest` 加两个可选字段：`create: Bool?`、`cwd: String?`。`create == true` 时忽略 sessionId，走新建。
  命令行不改：命令行给 agent 用，agent 不需要新建成员。

### 核心（API.addMember 的新建分支）

1. 校验，和原来一样：成员名格式、保留字、群里不能重名。另外：
   - 群不能是集群主群或集群子群，否则拒绝并说明「集群群聊请用 spawn」。原因：群主会被复制进每个子群，
     复制出来的那一行没有 tmux，同一个会话会被另起后台进程（就是之前遇到的双进程问题）。
   - 工作目录必须在物理机上存在，而且是目录。
   - Claude：目录必须在 /Users 下（虚拟机只看得到这里）。虚拟机按集群同样的规则选：只有一台在运行就用它；
     没有在运行的报错；有多台也报错，提示先只开一台（第一版不加虚拟机选择）。
2. 加成员：`headless: true`，`tmux: kk-<群ID>-<成员名>`，`cwd` 用选的目录。
   - Claude：`sessionId` 预先生成一个 UUID，`vm` 为选中的虚拟机。
   - Codex：`sessionId` 先留空，第一轮跑起来后回填，和集群 tester 一样。
3. 发入群说明（Prompts.intro，普通群的那份）当第一条消息，排队投递：
   - Claude：用途 `.notice`。第一次投递时 ensureTmuxSession 发现会话文件不存在，用 `--session-id` 新建（带 hook）；
     界面就绪后按「启动后正面空闲」记成空闲，再贴入群说明。
   - Codex：用途 `.bootstrap`，先 `codex exec` 把会话建出来、回填 sessionId（入群说明那一轮要求立即结束），
     之后的消息走 tmux，和集群 tester 一样。
4. 返回新成员。界面上它马上出现在成员列表里，状态是「正在启动」，几秒到十几秒后变成空闲。

### 移出和解散

已有逻辑会停掉投递并关掉 tmux（API.removeMember / dissolveGroup 里有 `Tmux.kill`），不用改。
会话文件留着，和集群一样（以后想看历史，可以在会话页打开）。

### 不做的（第一版）

- 集群群聊里新建（原因见上）。以后要做，先解决「群主复制进子群时带上 tmux 托管」的问题。
- 新建时选具体哪台虚拟机（现在只有一台）。
- 给新会话预设第一条任务：入群说明之后，直接在群里发消息就行。

## 验证（测试核心 7799）

1. 新建 Claude：选测试目录，成员出现；虚拟机里 tmux 起来、hook 就绪；入群说明送达；
   在群里发消息，它用测试命令包装回复，只落测试库。在界面里打开它的终端能交互。
2. 新建 Codex：codex exec 建出会话、sessionId 回填；之后的消息走 tmux 送达并回复。
3. 拒绝：集群群聊、目录不存在、Claude 目录不在 /Users 下、成员名重名、没有虚拟机在运行。
4. 移出成员、解散群：tmux 和进程都退出，没有残留（用 orphan-tmux.sh 核对）。
5. 紧急消息能打断新建的 Claude 成员（复用第 6 步）。
6. 界面：工作目录在第一项；有默认目录；能选文件夹；按钮置灰规则正确。
