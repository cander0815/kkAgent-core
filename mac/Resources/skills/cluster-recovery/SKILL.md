# 集群恢复

先停受影响的写入/同类操作，保留现场；其他独立工作可继续。在 koala-ticketing 先读 [项目适配](../cluster-command/references/koala-ticketing.md)。任何恢复均不绕过审批、不擅停用户服务、不覆盖未提交成果。

## 上下文压缩、交接与重开

重新读取本技能、适用 AGENTS.md、最新用户决定与台账顶部快照，按当前动作再读派发/统筹/验收技能。快照至少包含目标/授权、决定和任务书入口、组/会话/执行者状态、各 SHA、资源租约、未提交改动、未验与下一步；不要全量加载历史消息。

只读核实际 HEAD/工作区、进程加载、当前可用工具/权限、执行者最近实质进展及租约。发现旧记录冲突先用最新可核实事实修正，无法确认的写“未知”，不恢复旧消息中的过期授权。不以会话存在冒称正在执行。

## 分类恢复

### 资源已授权但仍等旧消息

先看最新租约与投递记录。已 delivered 不能判投递失败，更不代表已执行。向实际执行者发送一次当前唯一快照：覆盖哪条旧授权、唯一持有人、可立即做什么、恢复/释放条件与下一位；避免多级转述。核对实际执行后再更新状态。

### 消息写入但未确认

只读核当前会话界面/工具状态及允许访问的投递元数据：正常 pending 等待，已 delivered 不重发。仅在完整残留输入且没有用户正在输入、并已核清不会重复提交时，提交现有内容一次，再观察实际处理。

需要解除队列时，只用已核实、当前授权的界面等价 API；不直接改投递库状态、不伪标成功。跨群同名角色通道判“发给自己”时，由根转发最小合同，写明目标组/角色、来源、SHA和当前状态，不要求反复使用失效通道。

### 启动失败或运行中断

首条失败且会话不存在，先查工作树、tester状态、分支与所有未提交改动，确认无已做业务才重建同一任务；不重复计完成。已有进展则从最新报告/现场续接，不能用旧交接覆盖新 SHA。会话表面活跃但实际返回输入框时，核实后续接原通道，不直接另开重复执行者。

### 权限或连接变化

区分连接拒绝、审批拒绝、会话权限变化、配置保存但未加载。旧拒绝不永久等于当前禁止，基于当前加载状态走正常授权路径；明确拒绝不能换 CDP、身份或隐藏 API 绕过。不让用户无谓改全局配置，不冒称保存配置就已生效。

### 账号不一致或误写

身份断言不一致立即停输入/业务写入，先保留只读网络/数据库证据。只有能唯一确认原值、误写完整 payload、时间/主键和影响范围，且精确恢复已获授权时，才事务恢复指定行；证据不足移交用户，不猜默认值、不批量清空、不硬删审计。核恢复结果后才能写“已恢复”，公开证据去敏。

### 原生授权、保存或分享层卡住

停止同类原生调用，不叠新层。restore 撤销替身不证明真实系统层关闭。保留截图、备份和证据，核当前注册官方恢复能力及是否已执行，最多一次明确恢复；失败请求人工。截图仍有原生层就不释放模拟器，不循环坐标、restore或隐藏 API试探。

## 挂起或恢复完成

真外部依赖列最小缺口、有权提供者及恢复条件；保留全部新 SHA/脏文件和最后已验结论，安全归档释放席位，不把挂起当完成。不得编造配置、擅开计费或读取别项目秘密。

恢复后更新快照和租约，以实际执行结果确认恢复；关键阻塞出现/解除主动汇报。只对当前必须行动者发必要指令，不广播所有组，不重复触发已完成 tester 工作。
